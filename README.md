README - Ejercicios Flutter StatefulWidget
Descripción

Este proyecto contiene 6 ejercicios desarrollados en Flutter utilizando StatefulWidget.
Los ejercicios permiten practicar el manejo de estados, botones, formularios, colores, mensajes dinámicos y componentes interactivos en Flutter.

Tecnologías utilizadas
Flutter
Dart
Material Design
Ejercicios incluidos
Ejercicio 1 - Contador de puntos

Aplicación que permite:

Sumar puntos.
Restar puntos.
Reiniciar el contador.
Mostrar el puntaje actual.
Conceptos utilizados
StatefulWidget
setState()
ElevatedButton
Text
Row y Column
Ejercicio 2 - Mensajes motivacionales

Pantalla que cambia mensajes motivacionales al presionar un botón.

Mensajes incluidos
“Sigue practicando”
“Vas muy bien”
“No te rindas”
“Cada error también enseña”
Conceptos utilizados
Listas en Dart
Índices
setState()
Botones dinámicos
Ejercicio 3 - Cambio de color de tarjeta

Aplicación donde una tarjeta cambia de color según el botón seleccionado.

Colores disponibles
Azul
Verde
Rojo
Conceptos utilizados
Container
BoxDecoration
Manejo de colores
StatefulWidget
Ejercicio 4 - Mostrar y ocultar información

Pantalla que muestra u oculta información sobre Flutter.

Funcionalidades
Mostrar información
Ocultar información
Cambio dinámico del botón
Conceptos utilizados
Variables booleanas
Condicionales
Widgets dinámicos
Ejercicio 5 - Formulario sencillo

Formulario que solicita:

Nombre

Ciudad

Después muestra un mensaje personalizado.

Ejemplo
Hola, Laura. Estudias ADSO y vives en Facatativá.

Captura de datos
Ejercicio 6 - Confirmación de asistencia

Aplicación que permite confirmar asistencia usando un CheckboxListTile.

Estados posibles
Asistencia confirmada
Asistencia pendiente
Conceptos utilizados
CheckboxListTile
Variables booleanas
Actualización de estado
Cómo ejecutar el proyecto
1. Crear un proyecto Flutter
flutter create ejercicios_flutter
2. Entrar a la carpeta
cd ejercicios_flutter
3. Reemplazar el contenido de lib/main.dart

Copiar el código del ejercicio que se desea ejecutar.

4. Ejecutar el proyecto
flutter run
Estructura básica
lib/
 └── main.dart
Requisitos
Flutter SDK instalado
Visual Studio Code o Android Studio
Emulador o dispositivo físico
